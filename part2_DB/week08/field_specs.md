# *Paranthropus* and *Homo* Paleoecology Database - Field Specifications Document
**Author:** Claire Brandes /
**Date:** October 13, 2026

## Table: localities

| Field Name  | Data Type | PK/FK | NOT NULL | UNIQUE | DEFAULT | CHECK | RATIONALE                                                                                            |
|-------------|-----------|-------|----------|--------|---------|-------|------------------------------------------------------------------------------------------------------|
| locality_id | Integer   | PK    | YES      | YES    | -       | -     | NOT NULL: Surrogate key; no stable natural key exists.                                               |
| country     | Text      |       | YES      | NO     | -       | -     | NOT NULL: Every site is in a country, so it's always known.                                          |
| site        | Text      |       | YES      | NO     | -       | -     | NOT NULL: The site specification is the minimum needed to identify a locality.                       |
| formation   | Text      |       | YES      | NO     | -       | -     | NOT NULL: Formation and member information is crucial to link hominins with paleoecological proxies. |
| member      | Text      |       | YES      | NO     | -       | -     | NOT NULL: Formation and member information is crucial to link hominins with paleoecological proxies. |

## Table: hominin_occurrences 

| Field Name      | Data Type | PK/FK                            | NOT NULL | UNIQUE | DEFAULT | CHECK                                                                                                        | RATIONALE                                                                                                                                                                         |
|-----------------|-----------|----------------------------------|----------|--------|---------|--------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| occurrence_id   | Integer   | PK                               | YES      | YES    | -       | -                                                                                                            | NOT NULL: Surrogate key; no natural key exists for this  specific type of occurrence data.                                                                                        |
| scientific_name | Text      |                                  | YES      | NO     | -       | scientific_name IN ('Paranthropus_aethiopicus','Paranthropus_boisei','Paranthropus_robustus','Homo_habilis') | NOT NULL: A taxonomic name must exist for this database to run the types of queries it was designed for. CHECK: Controlled vocabulary for species of interest will prevent typos. |
| locality_id     | Integer   | FK (localities.locality_id)      | YES      | YES    | -       | -                                                                                                            | NOT NULL: This field is a foreign key that links hominin occurrence data to localities.                                                                                           |
| publication_id  | Integer   | FK (publications.publication_id) | YES      | YES    | -       | -                                                                                                            | NOT NULL: This field is a foreign key that links hominin occurrence data to their original publication.                                                                           |

## Table: proxies

| Field Name       | Data Type | PK/FK                            | NOT NULL | UNIQUE | DEFAULT | CHECK                                                                                                                                                                            | RATIONALE                                                                                                                                                                                                                                                                                                        |
|------------------|-----------|----------------------------------|----------|--------|---------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| proxy_id         | Integer   | PK                               | YES      | YES    | -       | -                                                                                                                                                                                | NOT NULL: Surrogate key; no natural key exists for this type of data.                                                                                                                                                                                                                                            |
| type             | Text      |                                  | YES      | NO     | -       | type IN ('faunal_list','enamel_isotopes','paleosol_isotopes')                                                                                                                    | NOT NULL: The type of proxy data is required to run the types of queries this database was built for. CHECK: Items will certainly be added to the controlled vocabulary over time, which will maintain consistency in the database despite the same proxies sometimes bearing different names in the literature. |
| unit_of_analysis | Text      |                                  | YES      | NO     | -       | unit_of_analysis IN ('assemblage_level','specimen_level','sediment_level'); faunal_list = assemblage_level, enamel_isotopes = specimen_level, paleosol_isotopes = sediment_level | NOT NULL: This field will be auto-populated from the type field, which is also NOT NULL. CHECK: Controlled vocabulary ensures the relationship between type of proxy data and the unit of analysis remains consistent.                                                                                           |
| locality_id      | Integer   | FK (localities.locality_id)      | YES      | YES    | -       | -                                                                                                                                                                                | NOT NULL: This field is a foreign key that links proxy data to localities.                                                                                                                                                                                                                                       |
| publication_id   | Integer   | FK (publications.publication_id) | YES      | YES    | -       | -                                                                                                                                                                                | NOT NULL: This field is a foreign key that links proxy data to its publication.                                                                                                                                                                                                                                  |

## Table: publications

| Field Name     | Data Type | PK/FK | NOT NULL | UNIQUE | DEFAULT | CHECK | RATIONALE                                                                                                                   |
|----------------|-----------|-------|----------|--------|---------|-------|-----------------------------------------------------------------------------------------------------------------------------|
| publication_id | Integer   | PK    | YES      | YES    | -       | -     | NOT NULL: Surrogate key; a natural key exists (citation or DOI) but citations are long and not every publication has a doi. |
| citation       | Text      |       | YES      | YES    | -       | -     | NOT NULL: Every entry *will* have a citation.                                                                               |
| year           | Integer   |       | YES      | NO     | -       | -     | NOT NULL: Every citation *will* be associated with a year of publication.                                                   |
| doi            | Text      |       | NO       | YES    | -       | -     | NULL: This field may be null as older publications may not have a DOI.                                                      |
