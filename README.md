# Computational Paleobiology - Section 1 Project 

### Course Context:
ANT 388 (Computational Paleobiology), UT Austin, Fall 2026

### Repository Structure:
*Part1_OS* Contains work for weeks 1-4, where we learned the ins-and-outs of the operating system and command line. 
- *Week01* focused on a basic introduction to the OS and command line  
- *Week02* focused on the posix shell, pipes and filters
- *Week03* focused on shell scripting
- *Week04* focused on version control and reproducible research

### Dependencies 
- These projects use bash/zsh on macOS
- awk, sed, grep, sort, cut, and curl are required tools

### Usage 
Make scripts executable by running:
```bash
chmod +x [script name]
```

### Data 
Datasets can be retrieved from the [Origins Database] (paleocore.org/origins/).
