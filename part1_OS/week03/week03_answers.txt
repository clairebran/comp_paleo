## Part 6

Option D — Qualified vs. unqualified identifications by formation
Do some formations produce more taxonomically certain identifications than others? For each formation, calculate the number of specimens with a non-empty identificationQualifier vs. those with an empty qualifier. Which formation has the highest proportion of uncertain identifications?

Command: tail -n +2 otb_fossils.tsv | \
awk -F '\t' '{
    if ($19 != "") {
        if ($23 ~ /.+/) {
            print $19 "\tUncertain"
        } else {
            print $19 "\tCertain"
        }
    }
}' | \
sort | \
uniq -c | \
awk '{
    count = $1
    status = $NF
    
    formation = $2
    for (i = 3; i < NF; i++) {
        formation = formation " " $i
    }
    
    if (status == "Certain") {
        certain[formation] = count
    } else {
        uncertain[formation] = count
    }
}
END {
    printf "%-15s %10s %10s %15s\n", "Formation", "Certain", "Uncertain", "% Uncertain"
    
    max = -1
    maxformation = ""
    
    for (f in certain) {
        c = certain[f]
        u = uncertain[f] + 0
        total = c + u
        percent = 100 * u / total
        
        printf "%-15s %10d %10d %14.1f%%\n", f, c, u, percent
        
        if (percent > max) {
            max = percent
            maxformation = f
        }
    }
    
    for (f in uncertain) {
        if (!(f in certain)) {
            u = uncertain[f]
            
            printf "%-15s %10d %10d %14.1f%%\n", f, 0, u, 100.0
            
            if (100 > max) {
                max = 100
                maxformation = f
            }
        }
    }
    
    printf "\nHighest proportion of uncertain identifications: %s (%.1f%%)\n", maxformation, max
}'

The four unix tools are tail, awk, sort, and uniq
Tail removes the header row
Awk looks ar the formation and identification qualifier columns
Sort puts identical formation/status combinations together
Uniq -c counts the consecutive identical formation/status combinations 

Answer: The results show that the Koobi Fora and Shungura formations contain the highest number of qualified specimens. Without further research, the output alone could suggest a few things. One possibility is that these two formations are characterized by the worst preservation conditions, this yielding fossils that are comparatively harder to identify. It could also be that different species are more abundant at different sites, and that species with less robust hypodigms are more abundant at these sites and thus more difficult to identify for that reason.
