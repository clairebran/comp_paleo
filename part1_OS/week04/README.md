# Week04 Repository 

*This week focused on version control and reproducible research*

Scripts in this repository include:
- *batch_inspect.sh:* Inspects all TSV files in a directory and reports basic stats.
- *check_catalog_numbers.sh:* Checks that all catalog numbers in a TSV file begin with a given prefix.
- *dataset_report.sh:* Generates a summary report of all TSV files in a directory.
- *formation_counts.sh:* Prints specimen counts for a list of formations.
- *hello_researcher.sh:* Prints the date, researcher name, and workind directory.
- *validate_tsv.sh:* Checks if a TSV file is well-formatted.
